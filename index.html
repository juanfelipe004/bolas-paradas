Guia de uso do sistema
Objetivo do software
Ferramenta para análise de bolas paradas, permitindo registro, filtragem, exportação e avaliação tática.

⚠️ IMPORTANTE: O SISTEMA NÃO ARMAZENA OS EVENTOS APÓS RECARREGAR A PÁGINA OU SAIR DO NAVEGADOR. SE PRECISAR PAUSAR OU ENCERRAR O TRABALHO, UTILIZE "EXPORTAR CSV" PARA SALVAR O PROGRESSO E PODER RETOMAR POSTERIORMENTE IMPORTANDO O ARQUIVO NOVAMENTE.

Como registrar um evento (Origem → Alvo → Finalização)
  • Passo 1: Clique no mapa no local exato de onde a bola parada foi cobrada (ORIGEM).
  • Passo 2: Clique no primeiro destino da bola após a cobrança (ALVO) — ex: primeiro poste, segundo poste, marca do pênalti. Uma linha é desenhada automaticamente ligando os dois pontos.
  • O modal abre automaticamente após o alvo ser definido. Preencha informações de cobrança, lado, primeiro contato, resultado, etc.
  • Caso exista finalização, o local exato dela continua sendo marcado separadamente no mapa do gol (aba Resultado) — o alvo da cobrança não precisa ser o mesmo lugar da finalização, pois entre os dois pode haver desvio, disputa, 2ª bola, etc.
  • Pressione Esc a qualquer momento antes do modal abrir para cancelar a marcação da origem.
  • Salvar registra o evento na base interna.
Como editar/remover eventos
  • Clique em uma bolinha já existente → abre modal de edição.
Filtragem e visualização
  • Mostrar: ofensivo / defensivo / ambos.
  • BP: escanteio / falta indireta.
  • Lado: direito / esquerdo / central.
  • Mapa: controla se o marcador de finalização aparece no mapa principal. A seta da cobrança é sempre exibida.
  • Heatmap: ON/OFF para visualizar densidade de ações.
  • Filtros: abre o painel com filtros avançados (chips) por bola parada, situação, tipo, abertura, lado, 1º contato, finalização, qualidade, altura, resultado, falha e 2ª bola.
Dashboard estatístico
  • KPIs, gráficos de distribuição/comparação e insights automáticos, calculados a partir dos filtros aplicados.
  • Jogadores e cobradores possuem ranking automático.
Como funciona a Tomada de Decisão
  • Baseia-se em volume (quantidade) + eficiência (gols, finalizações, 1º contato) + risco (transições).
  • Ofensivo considera: gols, finalizações, 1º contato, continuidade.
  • Defensivo considera: gols sofridos, finalizações contra, transições.
  • Recomenda priorização com base estatística, não opinião.
Exportação
  • Exportar CSV → exporta tabela bruta com todos os eventos.
  • Importar CSV → importa tabela bruta com todos os eventos já feitos.
  • Exportar PNG/PDF → representação visual + relatórios.
